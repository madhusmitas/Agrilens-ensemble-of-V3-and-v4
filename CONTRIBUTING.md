# Contributing to Agrilens-ensemble-of-V3-and-V4

Thank you for your interest in contributing! We welcome help from the community to make this project better. To keep things organized and high-quality, please follow these guidelines.

## How to Contribute

### 1. Reporting Bugs & Feature Requests
* Search existing Issues to make sure your point hasn't already been raised.
* If it's a new issue, open a new Issue using the provided templates.
* Clearly describe the problem, including steps to reproduce it and your environment details.

### 2. Submitting Code Changes (Pull Requests)
1. Fork the repository and create your branch from `main` (e.g., `feature/your-feature-name` or `fix/bug-name`).
2. Make your changes in a clean, isolated commit history.
3. Ensure your code follows the project's formatting and style guidelines.
4. Run all local tests to ensure nothing is broken.
5. Open a Pull Request (PR) with a clear title and a description explaining *what* you changed and *why*.

## Code Review Process
* All submissions require a code review by a maintainer before merging.
* Be open to feedback! We may ask for small adjustments or testing before approval.

## Community Code of Conduct
Please be respectful, constructive, and helpful in all issues, PR discussions, and comments.
