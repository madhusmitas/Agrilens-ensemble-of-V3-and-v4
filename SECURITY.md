# Security Policy

## Supported Versions

We actively monitor and patch security vulnerabilities. Please only use the supported versions listed below:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

**Please do not open public GitHub Issues for security vulnerabilities.**

If you discover a security flaw or a potential exploit in this project, please report it safely using **GitHub Private Vulnerability Reporting**:

1. Go to the **Security** tab at the top of this repository.
2. Click on **Vulnerability reporting** on the left sidebar.
3. Click the **Report a vulnerability** button.

### What to Include
* A detailed description of the vulnerability.
* Step-by-step instructions or a proof-of-concept script to reproduce the issue.
* The potential impact if exploited.

We will acknowledge your report within 48 hours and work to patch the issue privately before making a public disclosure. Thank you for keeping our users safe!
